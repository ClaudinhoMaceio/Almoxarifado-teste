# 📱 Instalação Local - Gestão Técnica DASCO

## Como Instalar no Computador

### Opção 1: Instalação Automática (Recomendado)

1. **Abra o sistema no navegador** (Chrome, Edge ou Firefox)
2. **Procure o botão verde "INSTALAR"** no canto superior direito
3. **Clique no botão** quando aparecer
4. **Confirme a instalação** na janela que abrir
5. **Pronto!** O aplicativo será instalado no seu computador

### Opção 2: Instalação Manual

#### No Chrome/Edge:
1. Abra o sistema no navegador
2. Clique no ícone de **três pontos** (⋮) no canto superior direito
3. Selecione **"Instalar aplicativo"** ou **"Instalar [Nome do App]"**
4. Confirme a instalação

#### No Firefox:
1. Abra o sistema no navegador
2. Clique no ícone de **menu** (☰)
3. Selecione **"Instalar"** ou procure pela opção de instalação
4. Confirme a instalação

## ✅ Funcionalidades da Versão Instalada

- ✅ **Funciona offline** - Todos os dados são salvos localmente
- ✅ **Acesso rápido** - Ícone na área de trabalho e menu iniciar
- ✅ **Dados seguros** - Tudo fica salvo no seu computador
- ✅ **Backup automático** - Sistema salva automaticamente
- ✅ **Sem necessidade de internet** - Funciona completamente offline após instalação

## 📂 Onde os Dados são Salvos

Os dados são salvos no **localStorage do navegador** e podem ser exportados como arquivo JSON através do botão "EXPORTAR BACKUP".

## 🔄 Atualizações

Quando houver atualizações do sistema:
1. O Service Worker atualiza automaticamente
2. Você pode exportar seus dados antes de atualizar
3. Importe o backup após atualizar

## 🆘 Suporte

Se tiver problemas com a instalação:
- Certifique-se de estar usando um navegador moderno (Chrome, Edge, Firefox)
- Verifique se o JavaScript está habilitado
- Tente em modo anônimo para verificar se não há extensões interferindo

## ☁️ Google Drive (Apps Script)

O arquivo do script agora está no projeto em:

- `GOOGLE_APPS_SCRIPT.gs`

Como usar:
1. Abra [script.google.com](https://script.google.com)
2. Crie um novo projeto
3. Copie todo o conteúdo de `GOOGLE_APPS_SCRIPT.gs` e cole no editor
4. Implante como **Aplicativo da Web** (executar como você e acesso para quem tiver o link)
5. Copie a URL gerada e cole no sistema no modal de Google Apps Script

## 📝 Notas Importantes

- **Backup regular**: Sempre exporte seus backups regularmente
- **Navegador**: Use sempre o mesmo navegador após instalar
- **Dados locais**: Os dados ficam salvos apenas no navegador onde instalou
